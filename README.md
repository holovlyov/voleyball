# 🏐 ВолейТренер

Безкоштовна тренерська дошка для волейболу, яка працює прямо в браузері: без встановлення, реєстрації та сервера. Достатньо відкрити сторінку на телефоні або комп’ютері.

## Можливості

- **Системи гри:** 5-1 та 4-2, шість ротацій, «Ми подаємо» / «Ми приймаємо», ліберо.
- **Вісім етапів:** стартова, подача, ігрова, розхід на атаку, пас, удар, страхування, захист.
- **Атака:** лівий край (4), правий край (2), швидка по центру (3), слайд, пайп (6), задня лінія (1).
- **Захист:** блок одиночний, подвійний або потрійний; система захисту — периметр, ротація, man-up; напрямок атаки суперника — ліво, центр, право, пайп, задня лінія.
- **Вигляд:** 2D зверху, 3D з обертанням і зумом, від 1-ї особи (очима гравця), від 3-ї особи (камера за спиною).
- **М’яч:** показує, на якій половині поля він лежить, у якій зоні, скільки метрів від сітки й на якій висоті; є слід м’яча.
- **Власне моделювання:** режим «✋ Правка» дозволяє перетягувати гравців і м’яч. Етапи можна перемикати вручну, ставити на паузу й рухати гравців у завмерлій ситуації.
- **Мій сценарій:** зберігайте розстановки як кроки й відтворюйте їх по черзі.
- **Тренажер:** програма ховає одного гравця, а ви торкаєтесь поля там, де він має стояти.

## Як користуватися

1. Оберіть систему (5-1 / 4-2), ротацію та хто починає розіграш.
2. Перемикайте етапи кнопками під полем або стрілками ◀ ▶ на полі.
3. Для атаки й захисту змінюйте параметри (тип атаки, блок, система захисту).
4. Хочете змоделювати свою ситуацію? Увімкніть «✋ Правка», перетягніть гравців і м’яч, потім натисніть «＋ Крок».
5. У 3D обертайте поле пальцем, масштабуйте двома пальцями або коліщатком миші.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub (наприклад, `volleycoach`).
2. Натисніть **Add file → Upload files**, завантажте `index.html`, `README.md` і `LICENSE`, потім **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**, гілку `main` і папку `/ (root)`, збережіть.
4. За хвилину-дві сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Локальний запуск

Відкрийте `index.html` у браузері. Потрібен інтернет: 3D-бібліотеку three.js сторінка підвантажує з CDN (cdnjs). Для роботи офлайн завантажте `three.min.js` (версія r128) у репозиторій і змініть адресу в тезі `<script src=...>` у `index.html`.

## Технічні подробиці

- Один файл `index.html`: HTML, CSS і JavaScript разом, без збирання.
- 3D-графіка: [three.js](https://threejs.org/) r128.
- Дані не надсилаються нікуди й не зберігаються: сценарії живуть лише на відкритій сторінці.

## Обмеження та плани

- Розстановки блоку та захисту — типові схеми; їх можна уточнити під вашу команду в об’єкті `T` і функції `dfn` у `index.html`.
- Сценарії не зберігаються після оновлення сторінки.
